# Vic Falls Connect — Next.js

A Next.js conversion of the supplied Vic Falls Connect HTML landing page.

## Requirements

- Node.js LTS
- npm

## Run

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Production

```bash
npm run build
npm start
```

## What was converted

- Original responsive layout and visual styling
- Next.js App Router
- TypeScript/TSX
- Next.js Google fonts via `next/font/google`
- Original SVG artwork
- CSS animations and responsive behavior
- IntersectionObserver reveal animation implemented in React
- Metadata/title/description
